A tiny Node program that writes exactly one word — "robit" — to `entry.txt` for make.fun's "One Word From Grandma" bounty. "Robit" is the word a grandma would text about AI: robot with one letter slipped, warm, a little baffled, and funny without any explanation.

## Run it

```sh
node main.ts
```

This writes the word to `$MAKEFUN_OUTPUT_DIR/entry.txt` (or `/output/entry.txt` when the variable is not set).
